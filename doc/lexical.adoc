= lexical: the string formats of JSON Schema for {cpp}
:toc: left
:toclevels: 1
:idprefix:
:sectanchors:
:example-caption!:
:attribute-missing: warn
:unicode-version: 17.0.0

lexical is a header-only library of validators for the string formats of
JSON Schema, in {cpp}20, one of the libraries of
https://github.com/webcpporg/webcpp[webcpp]. Each format is a function that
takes a `std::string_view` and answers `bool`, and, but `regex`, a Boost.URL
grammar rule, which composes with Boost.URL's combinators into grammars of a
program's own. Each is checked as its RFC or ECMA-262 defines it, against
the official JSON-Schema-Test-Suite, and `regex` against V8. Nothing
allocates but an IRI too long for its inline buffer, through a
`std::pmr::memory_resource`.

This page teaches lexical format by format: what each checks, its rules and
its examples. Every program it shows was compiled and run, natively and for
wasm32-wasip2, wasm32-wasip3 and emscripten, and printed the output shown
under it. The <<reference,reference>> that closes it lists every name the
headers declare.
