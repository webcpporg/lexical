== Changelog

What changed in lexical in each version of webcpp, newest first, one line
per change. "Unreleased" is what the next version brings. The release notes
of every version are on webcpp's index page.

[#lexical-changelog-unreleased]
=== Unreleased

// tag::unreleased[]
* Added the library: validators and Boost.URL rules for JSON Schema's string formats.
* Added dates, times and durations of RFC 3339, with a leap-second policy for v1.
* Added UUIDs, and JSON Pointers absolute and relative, with an index manipulation policy.
* Added IP addresses, URIs and URI references through Boost.URL, faithful to RFC 3986.
* Added IRIs and URI templates, mapped to URIs for Boost.URL within a memory resource.
* Added host names and e-mail addresses, internationalized ones judged by webcpp::idna.
* Added ECMA-262 patterns in u mode, checked by an allocation-free syntax validator, with Unicode 17 tables.
// end::unreleased[]
